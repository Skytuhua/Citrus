Citrus offline image feature pack

HEIC uses libheif 1.23.6, libde265 1.1.3 and Kvazaar 2.3.2, dynamically linked.
libheif and libde265: LGPL-3.0-or-later. Kvazaar: BSD-3-Clause.
The replaceable DLLs are in image/heic; no plugin search or system codec installation is required.
Original source archives, the Citrus bridge source and exact build script are supplied in
source/image inside the same-release Citrus-ThirdParty-Sources.zip.
See the installed SOURCE-DOWNLOADS.md for the exact download URL and checksum.
You may replace/relink the LGPL libraries for your own use under their license terms.
The bridge explicitly chooses the Kvazaar HEVC encoder; no x265 or AV1 substitution is used.
Output is 8-bit SDR, using the encoder's 4:2:0 color sampling; HDR/10-bit preservation is not claimed.
Transparent inputs use lossless HEVC bitstream encoding to retain exact alpha samples;
quality-based size reduction is limited for these images. Color sampling remains 4:2:0.
