# Citrus support

Start with [quick start](docs/QUICKSTART.md), [capabilities](docs/operations.md), [preview notes](docs/PREVIEW-NOTES.md) and [release notes](https://github.com/Skytuhua/Citrus/releases).

For help with Citrus, email [leo@citrous.app](mailto:leo@citrous.app) or visit [online support](https://citrous.app/support/).

Use [GitHub Issues](https://github.com/Skytuhua/Citrus/issues/new/choose) for reproducible bugs and feature requests. Include version, Windows build, display scale and steps. Describe the source format and codec where possible. Use a small sample you own and can share.

Do not post credentials, personal documents or unredacted desktop captures. Review logs before sharing them. For security concerns, use the [security policy](SECURITY.md).

This is a community-supported preview. No response time, service level, conversion fidelity or zero-delay guarantee is promised.
